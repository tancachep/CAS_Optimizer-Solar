9. Financial Model

Hình 5: Tab Kịch bản Đầu tư – Financial Analysis

9.1 Revenue Year 1

revenueSavings = (usedPeak × pricePeak) + (usedNormal × priceNormal) + (usedOffPeak × priceOffPeak) revenueExport = totalExported × gridInjectionPrice firstYearIncome = revenueSavings + revenueExport - costGridCharge

9.2 Degradation & Escalation

degradationFactor = (1 - 0.0055) ^ (year - 1) // 0.55%/year escalationFactor = (1 + 0.020) ^ (year - 1) // 2.0%/year annualRevenue = firstYearIncome × degradation × escalation

9.3 Loan (PMT)

r = annualRate / 12 PMT = (principal × r × (1+r)^n) / ((1+r)^n - 1)

9.4 NPV & IRR

NPV = -equity + Σ(CF_t / (1 + discountRate)^t) // discount: 10% IRR = rate where NPV = 0 (binary search, 100 iterations)

9.5 Payback

paybackYear = (year-1) + |prevCumulative| / netCashFlow[year]

Zero-Export (Safe Fit)

1. Find month with minimum consumption 2. Calculate base + variable load during daytime 3. Find MIN load during peak solar (11:00-13:00) on weekends 4. Target kWp = that minimum load value (1:1 ratio)
Safe Fit rất bảo thủ: thấp hơn 30-50% so với Optimal. Chỉ dùng khi KH tuyệt đối không muốn dư thừa.
